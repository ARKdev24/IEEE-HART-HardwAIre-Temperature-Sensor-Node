# IEEE-HART-HardwAIre-Temperature-Sensor-Node
This is a temperature sensor node developed for industrial grade

The sensor node was developed using PT1000 rtd sensors and ADC.
The data was being transmitteed to a gsteway via LoRaWAN.
The transmitter and receiver end contained an antenna manufactured by our team.
My contribution to the team was in the system architecture that led the initial selection of the project idea and data processing for the data that is received for a viewer to access the data in a easier way. I also created a predictor model to predict time remaing for reaching threshold. I also created a virtual dataset because we couldnt record a full month dataset in real time due to time contraints.
